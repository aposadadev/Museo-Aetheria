# Pieza Creativa Multimodal con IA: Museo Virtual de Arte Generado por IA

## Enlace a la pieza final
[Visitar Museo Virtual](https://museo-virtual-ia.example.com)

## Descripción del concepto creativo
Este proyecto presenta un museo virtual donde se exhiben obras generadas completamente con Inteligencia Artificial. 
La experiencia combina imagen, música, texto y web, creando un espacio inmersivo que busca transmitir la sensación de caminar por una galería futurista.

El recorrido muestra varias piezas visuales creadas con **Nano Banana**, cada una acompañada por un título y una descripción generados por **ChatGPT**, aportando un marco conceptual a la obra.  
El ambiente sonoro de fondo fue diseñado con **Suno**, con una pieza musical instrumental que evoca curiosidad y contemplación, ideal para un entorno de galería.  
Toda la experiencia se aloja en una web construida con **Gemini**, ofreciendo al visitante una navegación intuitiva y elegante.

El objetivo es explorar cómo diferentes herramientas de IA pueden colaborar en una única experiencia multimodal, mostrando el potencial creativo de estas tecnologías en el ámbito artístico.

## Herramientas utilizadas
- **Gemini** → Desarrollo de la web para la experiencia del museo.  
- **Suno** → Creación de la canción de fondo instrumental para el recorrido.  
- **Nano Banana** → Generación de las obras visuales expuestas en la galería.  
- **ChatGPT** → Generación de nombres y descripciones de las obras.
